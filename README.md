# Vishnu K — Full-Stack Developer Portfolio

A modern, responsive portfolio website showcasing full-stack web applications, technical skills, credentials, and projects built by **Vishnu K**.

## 🚀 Tech Stack

- **Frontend**: React 19, Tailwind CSS 4, JavaScript (ESM)
- **Tooling**: Vite 8, ESLint
- **Testing**: Node.js Test Runner

## 📁 Project Structure

```text
my_portfolio/
├── public/                # Static assets, resume documents, and icons
│   ├── favicon.svg
│   ├── og-image.png
│   ├── VISHNU_K.pdf       # Authentic PDF resume
│   └── VISHNU_K.docx      # Authentic Word resume
├── src/
│   ├── assets/images/     # Profile and project screenshots
│   ├── components/        # Modular React components
│   │   ├── about/         # About Vishnu K & highlights
│   │   ├── certifications/# QSpiders certification card
│   │   ├── common/        # Container, SectionHeading, ScrollReveal, ThemeToggle
│   │   ├── contact/       # Contact info, mailto/gmail links, copy actions
│   │   ├── education/     # Academic timeline & credentials
│   │   ├── footer/        # Footer navigation & copyright
│   │   ├── hero/          # Hero section with animated lights & profile photo
│   │   ├── layout/        # Navbar with smooth scroll & mobile menu
│   │   └── projects/      # Project cards & detail modal
│   ├── data/              # Data configuration (resume-driven)
│   ├── App.jsx
│   ├── index.css          # Core styles, animations, and Tailwind imports
│   └── main.jsx
├── tests/                 # Automated validation tests
└── package.json
```

## 🛠️ Getting Started

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Run Tests
```bash
npm test
```

### Lint Code
```bash
npm run lint
```
